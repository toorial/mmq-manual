PorkMS

PorkMS (Pork Marbling Measurement System) is a browser page for pork marbling. It estimates the fat area ratio on a muscle cross-section and turns that ratio into a marbling grade. Open PorkMS and start. No account is required.

This grade is not the NPPC 6-point marbling score used by the MMQ desktop program. Use PorkMS when you want the fat-ratio grade below. Use MMQ when you also need L*, a*, b*, an NPPC colour score and intramuscular fat.

What the page provides

  • No login. The page can be used as soon as it opens.
  • One image at a time. Import an image, measure it, and the row is stored.
  • History. Results stay in the history panel, newest or oldest according to the time sort on the page, and can be scrolled.
  • CSV export. The history can be downloaded as one CSV file.
  • Trial quota. Each visit allows 100 successful measurements. Ask the developer of PorkMS if you need more.
  • Local processing. Analysis runs in the browser. Images and numbers are not sent to a server.
PorkMS keeps the work on your computer. Refreshing or reopening the page resets the trial quota. It also clears a session that lived only in that page.

Animal measurement info

The form at the top is optional. It does not change the image analysis. Anything you type is included in the CSV file, which makes the sheet easier to trace.

Measure one image

  1. Fill in the form if you want a paper trail. Location, operator, breed, gender and date are all optional.
  2. Import an image. Click the upload area or drop a JPG or PNG file into the dashed box. A preview appears. The × control removes it.
  3. Start measurement. The button shows a busy state while the page analyses the file. A successful run uses one trial.
  4. Read the history row. The new row shows the time, a thumbnail of the original, a thumbnail of the marked image, the fat ratio and the marbling grade.
  5. Export or clear. Export all as CSV downloads the history. Clear all results removes the rows of the current session.

The standard-image strip on PorkMS holds six reference pictures, grades 1 to 6. Analyze under a reference picture runs that picture and adds a history row, which is a quick way to check the scale.

Large images take longer because the work is done in the browser. Wait until the busy state ends. Loading a file without clicking Start measurement does not use a trial.

Trial quota

  • A visit starts with 100 measurements. The remaining count is shown in the banner.
  • Only a successful measurement is counted.
  • The count returns to 100 when the page is refreshed or opened again.
  • At zero, Start measurement is disabled. Contact the PorkMS developer to continue.

Marbling grades

The grade follows the fat area ratio on the muscle cross-section.

How a marked image should be read

On the result thumbnail, green regions are fat (marbling) found by the page. The remaining area is the muscle region kept after preprocessing.

The page separates the sample with Otsu thresholding, filters it in Lab colour space, and uses connected components to keep a valid muscle region. Fat particles are then taken from block-normalised brightness. The fat area ratio is the input to the table above.

Desktop colour calibration, folder batching and IMF are described under How to use MMQ, not on this page.
